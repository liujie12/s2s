## 7. P2 定稿：`flutter_svg` + `assets/`

| 理由 | 说明 |
| --- | --- |
| 资产形态 | 图标的 MCP 产物与库内插画均为 SVG；84 张插画逐张转 `CustomPainter` 不现实 |
| 现有代码 | 自绘仅 36 个类目字形 + 脚印，`CategoryGlyph` 内部换渲染即可，调用方不变 |
| 包体 | 矢量资产，不引入中文字体包，增量可控 |
| 约束 | 迁移完成前，同一表面不得同时出现 `CustomPaint` 与 SVG 两套画法 |
