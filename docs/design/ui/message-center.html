03本稿做的取舍需评审确认的三处

  • 详情页底栏改成两键：左侧 128 宽描边「聊一聊」，右侧占满主按钮。原因是「联系 TA」是既有主转化出口，不能降为次按钮；要求里也没有规定两者并排的样式。
  • 已读只用文字：不做「已读」双勾图标、不做时间戳。双勾在中文语境里歧义大（易被读成「已发送」），文字更直白。
  • 申请卡的拒绝不留输入框：拒绝即一次点击，不给理由输入。给理由会让发布者觉得在写驳回信，实际采纳率会掉；需要解释时他可以直接在会话里说一句。
