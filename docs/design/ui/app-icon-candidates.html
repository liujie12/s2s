先定筛选规则

RULE 01

一图一符号

脚印与眼睛各自独立成图，不叠加、不嵌合。好处是每个符号都能单独缩到 24px，也便于按场景换用。

RULE 02

24px 先过关

每张卡片都附 24px 实缩。大图好看但小图糊掉的方案直接淘汰——桌面图标最终以这个尺寸存在。

RULE 03

两色、圆头、无渐变

只用 #0B7C8C 与白，沿用官网 IP 的「负形留白」；不写中文、不加阴影、不做细线。

如果要缩到四个

18 个里建议先留这四张进二筛：两只是「主图候选」，两只是「语义补充」。它们两两之间不会重复讲同一个点。

F-01 纯脚印

名字直给、24px 最稳，桌面主图首选。

风险：「找」只能靠名字，图形不讲动词。

E-01 单眼

承接「一眼看清」，符号最简，缩到 24px 仍是一只眼。

风险：眼形在工具类 App 里并不稀缺，需靠瞳色区分。

S-01 双气泡

唯一把「有/要」双向关系画出来的方向。

风险：两个形状在 24px 会粘在一起，要压扁或拉大间距。

T-01 丫字标

名字辨识度最高，适合做商店详情页与官网的主字标。

风险：单独一个「丫」字，产品语义为零。

选定后要同步换掉的八处

图标不是一张图，是一套资产。一次换完，避免桌面上新旧两个标并存。

01Android 自适应图标前景层（432×432，图形收在 72/108 安全区内）+ 背景色 #0B7C8C
02单色层 monochrome：Android 13 主题图标只认这一层，必须单独出
03通知栏 small icon：24dp 纯白透明，不能带底色
04启动页 / 闪屏：深底 #062E33 + 白标，避免冷启动白屏闪一下
05登录页品牌位：现为 Icons.travel_explore 占位（72px 圆底），换成本标去底版
06应用商店素材：512×512 商店图标 + 各尺寸截图角标
07官网 favicon / OG 分享图：与 App 主标同形，不要另画一版
08文档与法务页内的旧名「找鸭找」需一并替换（PRD、官网、协议文本）
05

需要你拍板的四件事

D1 · 主图选哪个族

脚印系（F-01）、眼睛系（E-01）还是供需系（S-01）？也可以先各留一个，再看商店五图里的表现。

D2 · 鸭子意象是否保留

保留 = 走 F-04 蹼印，老用户不迷路；不保留 = 走 F-01 或 E-01，语义更贴新名，但需要一次认知教育。

D3 · 要不要组合标

若允许「桌面一个符号、登录页另一个符号」，可以把 F-01 放桌面、E-01 放品牌位；否则只能选一个符号贯穿全场景。

D4 · 是否同批替换应用内品牌位

建议同批。登录页现在是占位图标，趁改名一次换掉，成本最低。
