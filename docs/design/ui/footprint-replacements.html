🔧 替换技术说明

  • ✅ 最小改动原则：只删鸭头 path 和 circle 眼点，原 evenodd 环形/path1-2 一字不动
  • ✅ 1:1 几何对齐：每个脚印的 scale = min(鸭头bbox宽/44, 鸭头bbox高/50)，精确覆盖原鸭头占位
  • ✅ transform 链顺序：translate(目标center) → rotate(14) → scale(s) → translate(-54 -45)，先定位后旋转再缩放
  • ✅ 颜色自适应：白底版本（full/compact/ios/foreground/splash/logo）用主色 #0B7C8C；主色底版本（inverse/mono/mini）用白色 #FFFFFF
  • ⚠️ empty-state 特殊：内部实心鸭头 + 父级 opacity=0.28，脚印 fill=#0B7C8C 继承透明度
  • 脚印固定几何：三趾 ellipse（40,35 / 54,30.5 / 68,35）+ 掌形 path，无任何装饰声纹
  • ✅ Android 桌面图标（Python 合成）：FP_SCALE=1.70 · FP_ROTATE_DEG=20° · X+12px · Y-18px（上移），详见 build_android_foonote.py
  • ✅ Flutter 底部导航栏（Dart CustomPainter）：inverse 变体结构——双波纹圈 + 中央圆盘 + 白色脚印反相，逐坐标复刻 duck-symbol-inverse.svg，未选中态灰色 textSecondary，详见 _FootprintPainter
  • ✅ 波纹圈保留：用户评审裁定导航栏发布键保留 inverse 档的外围双波纹圈（声纹），只做「鸭头→脚印」原位替换，环带参数与 SVG 完全一致
