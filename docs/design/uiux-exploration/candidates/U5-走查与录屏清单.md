## 2. 关键路径分镜（录屏用）

每条路径录一条 15–30 秒、1080×1920 竖屏或等比窗口的录屏；文件名 `A-path1-locate-to-detail.mp4`。录屏首页需静止 1 秒展示「演示数据（非真实供给）」标注。

| 路径 | 起始帧 | 操作序列 | 终点 | 判据 |
| --- | --- | --- | --- | --- |
| P1 定位 → 地图 → Pin → 详情 | `A5 定位失败` | 点「手动选择城市」→ 选第一城 → 点 Pin「3200」 | `S3 详情` | 面板收起、地图回填、详情标题与价格一致 |
| P2 列表 → 详情 → 返回 | `S1 首页` | 点分段「列表」→ 点首卡 → 点左上返回 | `S2 列表` | 列表筛选状态保留 |
| P3 发布 → 提交 → 失败 → 重试 | `S1 首页` | 点 FAB「发布」→ 点提交 →（D5）超时到 D6 → 点重试 | `D5 提交中` | 已填内容不丢、按钮进入 loading 且不可重复点 |
| P4 草稿恢复 | `D7 草稿与恢复` | 点「恢复草稿」 | `D1 无图发布` | 标题/描述/分类回填 |
| P5 零结果 → 引导发布 | `E1 静态空态` | 点「发布第一条」 | `D1 无图发布` | 空态文案与按钮一致，不出现假供给 |

P6（异常兜底，可选）：`C3`/`C4`/`C7` 分别点主按钮 → 回 `S2 列表`。

## 4. 敏感信息核对（外发前逐项）

| 项 | 检查点 |
| --- | --- |
| 图层/页面/文件命名 | 不含手机号、真实姓名、门牌、坐标 |
| 评论与版本名 | 不含个人信息与外链 |
| PDF 元数据 | 作者统一为 `s2s-design`，无本地路径 |
| 录屏 | 无通知弹窗、无账号信息、无剪贴板内容 |
| 分享链接 | 仅只读，链接不写入仓库与日志 |
