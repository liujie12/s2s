## 22. 图形资产与地图资产设计规范（2026-11-20）

### 22.1 资产分三层，各管一件事

| 层 | 尺寸 | 作用 | 出现位置 |

### 22.2 L1 品类字形：5 枚扩到 15 枚

**画布与笔法（沿用 §18.4，不新增口径）**：24×24 网格、安全区 2、**2px 描边**、圆头端点与圆角连接、**无填充**、单色 `#B8430F`、底 `#FFEDE3`。

> **清单口径已变更（2026-11-20，见 §22.26）**：下图「每大类 3 枚」**不再是字形清单**。命名与清单改由代码 `customGlyphNames`（36 个自绘名）唯一决定。下表仅保留为「首批 15 枚的历史来源」，其中 4 枚已改代码名（`KEY`/`TRUCK`/`BRUSH`/`WATER_ELEC`），9 枚标为废弃待移除。

**构图规则（2026-11-20 修订，原「主形 57% + 右下辅形」作废）**：**一枚只画一个物体，占满 24 网格**（安全区 2）。不再做「大类主形 + 独立辅形」的双图形并置——两个物体并排，小尺寸下先被读成两个不相干的东西，识别成本直接变成「看不懂」；且「购物袋 = 生活」「扳手 = 服务」的语义映射本身不成立（主形讲交易动作、辅形讲行业物件，两套语义硬拼）。

| 大类 | 三枚（各自单物体） |

| 工作 | 工牌 / 安全帽 / 简历 |

| 服务 | 水龙头 / 扫帚 / 灯泡 |

### 22.5 空态图：4 个，几何拼贴不画人

对象：空收藏、空发布、空消息、空结果。画布 120×120，由 **3–5 个几何块**组成（全部落在 24 网格、2px 描边），主块 + 1–2 个浅橙陪衬块（`#FFEDE3`，无描边）。

例：空收藏 = 三张层叠卡片（错位 12）+ 一枚心形；空结果 = 一个放大镜 + 两个错位卡片。**不画人物、不做拟物**：人物插画会引入风格与版权负担，且与「单色相 + 字形」的语言不一致。

### 22.8 地图可读性四条硬规则

1. 相邻图层明度差 ≥4%，否则真机户外光下糊成一片。

3. Pin 一律 4px 白描边，保证压在任何底纹上都读得清。
4. 地图底图按协议 §4 **不计入 G5 色面**——O1 的 J27 仍由 Pin 与信息卡承担，不能靠底图凑数。
