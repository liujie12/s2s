# 真实界面基线（2026-11-18）

> 状态：生效。自本文件起，**UI 设计基准 = 当前系统真实界面**（`lib/` 代码 + 真机截图）。
> 适用范围：`sds-app-v2` 探索文件后续全部改稿、评审与导出。
> 关联：[review-protocol.md](file:///d:/developer/code/aicoding/s2s/docs/design/uiux-exploration/review-protocol.md) §11。

## 0. 三条基线原则

1. **基准唯一**：界面结构、文案、状态、组件形态一律以当前 Flutter 实现为准。PRD 与 v1–v3 候选稿仅作参考，凡与真实界面冲突，以真实界面为准。
2. **不自创口径**：分类、供需态、价格、完整度、认证层级等业务语义只能取材于代码与 PRD 冻结口径；设计稿不得新增第六类、不得自拟供需色。
3. **竞品只借元素**：借鉴的是信息密度、卡片节奏、地图交互、筛选表达等**设计元素与思路**；禁止版式、配色、图标、文案的形似模仿（详见 review-protocol §11）。
4. **本文件不约束色板（2026-11-18 追加）**：真实界面只约束业务功能与内容；优化稿的视觉、配色、版式采用候选 A 色板，映射见 [manifest.md](file:///d:/developer/code/aicoding/s2s/docs/design/uiux-exploration/manifest.md) §16。

## 7.1 无障碍覆盖与缺口

- 已出画：系统字号 125% 与 200% 下的首页、列表、详情、发布、消息重排；44×44 触控目标；详情页 TalkBack/VoiceOver 朗读顺序。
- 代码依据：Flutter 默认跟随系统字号（`lib/` 无 `textScaler` 夹取）；按钮普遍声明 `minimumSize` 36–48；`Semantics` 见于地图 Marker、媒体区、车牌/选项/出发时间字段。
- 未实现（缺口，非画面问题）：「减弱动态」无 `MediaQuery.disableAnimations` 分支，系统关闭动画后轮播、转场仍会动。当前阶段只出设计优化稿、不改系统代码，故此项只登记、不实现。
- 未实现（缺口）：全局未做「大字体下把底部按钮改为两行」的极端兜底；200% 时部分密度高的弹层将进入滚动而非重排。
