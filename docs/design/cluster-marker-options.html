地图聚合图标 · 设计方案

对象：首页「丫圈」远景态聚合簇（当前为白底空心圆 + 居中数字）。尺寸对应现有三档 32 / 40 / 48。

当前样式为什么"丑"

  1. 空心白圆在浅色地图上几乎消失：白色填充与米色底图对比只有 1.1:1，只剩一圈 2px 细线，远景下像"没加载出来的占位"。
  2. 与单点 Marker 语言相反：单点是实心彩底 + 白图标，聚合却是空心白底 + 深色数字，同一张图上两套图形语言。
  3. 数字悬空：13px 数字放在 32px 空圆里四周留白过多，1 位数显得空洞，3 位数又挤。
  4. 重叠即脏：两个簇靠近时两个白圆互相压边，形成截图里那种"双层灰圈"。
  5. 无层次：没有投影/描边分离，簇和底图路网粘在一起。

建议

采用 A（实心分类色圆 + 白描边 + 轻投影）：只改填充/描边/阴影三处，尺寸体系、命中区域、点击逻辑全部不动；白描边顺带解决重叠时的"双层灰圈"，投影把簇从路网里拉出来。

若你更看重"一眼知道是几条"，选 B，但需要同时接受命中区从圆改矩形、三档尺寸重排、以及远景隐藏"条"字的额外规则。

C 与 D 不建议进入实现：C 在 32px 档可读性反而下降，D 与单点 Pin 争抢同一形状语义。
