- **匹配算法（Scope 校正：纯信息，不追踪撮合结果/历史信誉）**：
  - Baseline（阶段 0 规则加权，随时可回滚）：**时效 40% + 距离 40% + 完整度档 20%**（完整度档 = 🟢1.0/🟡0.5/🔴0.2）—— **2026-10-12 裁定：以此为准**（唯一口径见 PRD §6.11，与 BRD §10.1 QS 加权行、§2.7 裁剪表三处同源）；**原「距离 45% + 时效 25% + 分类 20% + 关键词 5% + 认证 5%」口径作废**；权重后台可配
  - T1 升级（Batch2，10%双轨灰度）：LR 一阶召回 + GBDT 二阶精排 + 供需双独立模型 + 分类 Hard Filter 前置 + 90/10 探索 + 双塔召回可选项
  - **⚠️ Scope 红线：特征集永远不取撮合反馈/历史撮合成功/信誉分/人格标签**，只允许使用：联系点击日志、位置精度、时效（发布/续期时间）、分类匹配、认证状态、关键词/类目 ID、信息完整度档（🟢/🟡/🔴）这 7 类纯信息信号
  - 独立 Feature Flag 灰度开关 + 中央降级按钮：一键回滚 Baseline
- **发布模板引擎**：JSON Schema 驱动，分类 ID 映射模板，前端通用渲染器；叠加 T2 AI 辅助生成：**阶段① 调已备案境内大模型 API**（2026-10-12 裁定；**阶段② 预留** = 语料达标后 QLoRA 微调 3B，Apache 2.0 基座如 Nanbeige4.1-3B）+ 严格 Scope 四步管线（Scope 提取交叉验证→Prompt限死→逆向比对）= 幻觉率 ≈ 0
- **AI 调用成本控制（Scope 校正：不按信誉分级）**：按「实名状态+信息完整度档」分层（实名+🟢=20次/实名+🟡=10次/未实名/🔴=3次）/天；发布页打开瞬间后台预生成；
- **AI 防御体系（三道后处理，纯信息合规不评人格）**：① 敏感词/类目标签过滤 ② AI 生成内容与 Scope 源交叉一致性比对（幻觉拦截） ③ 违规内容 1% 抽审（不分发布者等级，只按内容抽检）；再加 AI 生成内容检测（DetectGPT/AIthentic，开源准确率>92%）+ SimHash 重复指纹去重；
- **分级管理（Scope 校正：信息本身分级，不做人的信誉分级）**：信息完整度三档规则引擎（if-else 纯规则，无分位数/状态机依赖）：~~必填项完整度 50% + 位置精度 30% + 类目匹配度 20% → 三档阈值：≥85%=🟢 / 50-84%=🟡 / <50%=🔴~~ **该加权公式已作废，以 PRD §9.8「三条件计数」为准**（纠正记录见条目 `:623`）；**基础实名权限两档（未实名=每日看 3 条详情防爬 / 实名=无限次发无限次看）**；不做商业化分级售卖、不做升档培育期、不做三方制衡复审。
- **联系方式通道（Scope 校正：永久单轨，不做 IM）**：只做统一联系方式中转页（电话/VX 二选一 + 号码中间 4 位脱敏 + 点击复制/拨出触达埋点）；**永远不接 IM SDK、不做文本聊天、不设 DAU 阈值切换、不做付费中转**；中转脱敏日志保存 30 天自动清理。

#### 本产品特有的合规风险点（须提前规避）

1. **UGC 内容属性明确**：产品含用户自主发布信息 + 陌生人联系，安卓渠道判定为「社区类」，**个人主体一律拒审**，必须企业主体（已有执照，此项已解）。
2. **不触发 ICP 经营许可证（B25）的红线**：只要出现会员充值 / 付费解锁 / 虚拟打赏 / 平台广告 / 商家入驻**任一项**，五大安卓商店即强制要求 ICP 许可证（门槛：注册资本 ≥100 万 + 3 人连续 1 个月社保）。**本产品 Scope 已永久排除支付与商业化（见 PRD 红线），恰好规避此项** —— 这条红线现在成了排期上的护城河，**不可为增收而破**。
3. **位置权限是高频驳回点**：地图为核心功能，定位权限申请必须有明确用途说明，且首启前不得静默获取。
4. **算法备案潜在风险**：BRD 规划的 Batch2 LR+GBDT 匹配属「个性化推荐算法」，可能触发《互联网信息服务算法备案》。**内测包阶段用规则加权（阶段 0）不触发**，上架后若开启模型推荐需评估此项。


### 2.7 9/30 内测包范围裁剪（28 工作日单人产能约束）
