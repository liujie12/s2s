## 一、引言

本政策由 **【待填：公司全称，工商登记名称】**（以下简称"我们"）制定，适用于我们运营的「找鸭找」移动客户端（以下简称"本产品"）。

我们深知个人信息对你的重要性，将按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》《常见类型移动互联网应用程序必要个人信息范围规定》《移动互联网应用程序信息服务管理规定》《未成年人网络保护条例》等法律法规的要求，采取相应的安全保护措施，尽力保护你的个人信息安全可控。

**核心承诺**：

1. **最小必要**：只收集实现功能所必需的信息，不收集与提供服务无关的个人信息；
2. **告知同意**：在你明确同意本政策前，**不读取任何设备信息、不申请定位权限、不初始化任何第三方 SDK**；
3. **可拒绝**：你可以拒绝或撤回同意；拒绝不影响你浏览本产品的基本内容（地图与定位功能将不可用）；
4. **境内存储**：本产品服务器部署在中国境内，个人信息存储于中国境内。

## 二、我们如何收集和使用你的个人信息

我们**逐项对应**说明收集的信息、用途与是否必要：

| # | 信息种类 | 收集场景 | 用途 | 是否必要 | 拒绝的后果 |
|---|---|---|---|---|---|
| 1 | **手机号码** | 注册 / 登录（短信验证码） | 账号注册与登录、账号安全验证、**联系中转时的身份确认** | **必要**（无手机号无法注册账号） | 无法注册/登录，仅可浏览公开信息 |

| 5 | **资质认证材料**（营业执照、行业资质证照图片） | 你**主动**申请资质认证时 | 人工审核资质真实性，用于高敏感类目发布准入 | 非必要（仅高敏感类目要求） | 无法发布需资质的高敏感类目信息 |

### 2.1 敏感个人信息与单独同意

以下属**敏感个人信息**，我们仅在取得你的**单独同意**后处理：

- **身份证号、姓名**（实名认证）：仅用于身份核验。核验通过后，我们**只保存不可逆哈希值与身份证号后 4 位明文**，**不保存身份证号完整明文**；证照原件图片**在核验完成后 7 天内删除**。
- **精确位置信息**：仅在你在系统弹窗中授权定位后收集；你可随时在系统设置中关闭。

本产品集成的第三方 SDK 如下（**新增 SDK 时我们将更新本政策并重新征得同意**）：

> **已确认无需列入客户端 SDK 清单的服务**（因其为**纯服务端 API 调用**，不引入客户端 SDK、不直连终端）：实名认证（阿里云实人认证 · 信息核验）、短信验证码服务、对象存储（阿里云 OSS）。上述服务商仅在其提供服务所必需的最小范围内接触相关数据。

## 三、我们如何存储你的个人信息

1. **存储地点**：中国境内（【待填：服务器所在地，如"阿里云华东/华北节点"】）。目前**不涉及**个人信息出境。
2. **保存期限**（超出期限将删除或匿名化）：

| 信息种类 | 保存期限 |
|---|---|
| 账号基本信息（手机号、昵称等） | 账号存续期间；注销后删除或匿名化 |
| 实名认证信息 | 身份证号**不可逆哈希 + 后 4 位明文**，账号存续期间；注销后删除 |
| 实名认证**证照原件图片** | 核验完成后 **7 天内删除** |
| 发布内容 | 按其有效期（默认 **7 天**）；连续 **14 天**未刷新自动下架，仍保留于"我的发布" |
| 联系中转脱敏日志 | **30 天**自动清理 |
| 设备与访问日志 | 按安全合规要求的最短必要期限保存 |
| AI 解析输入与结果（去标识化后） | 用于模型优化的，保存至项目终止或你撤回同意时删除 |

## 四、我们如何共享、转让、公开披露你的个人信息

1. **我们不会出售你的个人信息**。
2. **共享**：仅在下列情形共享，且要求接收方遵守同等保护义务：
   - 履行功能所必需的服务商（如地图服务、短信服务、实名核验、对象存储）——见第二条 2.2；
   - 你主动使用"联系中转"功能、选择向对方展示联系方式时（此时仅向你选择的目标展示**脱敏/经你同意**的联系方式）；
   - 法律法规要求或有权机关依法要求时；
   - 取得你的**单独同意**的其他情形。
3. **转让**：原则上不转让；如发生合并、分立、收购等，将告知你并要求承继方继续受本政策约束，否则重新征得同意。
4. **公开披露**：除你主动发布的信息（将在本产品内公开展示）外，不公开披露你的个人信息。

## 五、你的个人信息权利

你对自己的个人信息享有下列权利，可通过本政策第九条的联系方式行使（我们将在 15 个工作日内答复）：

1. **查阅、复制**：查阅获知你账号下的个人信息；
2. **更正、补充**：更正不准确的个人信息；
3. **删除**：在你撤回同意、注销账号，或处理目的已实现等情形下请求删除；
4. **撤回同意**：关闭位置权限、关闭 AI 优化用途（见第八条）等；
5. **注销账号**：通过 **「我的」→「设置」→「注销账号」** 提交注销申请；注销后账号内相关信息将按第三条期限被删除或匿名化（法律法规另有要求的除外）；
6. **投诉举报**：对本政策或个人信息处理有疑问、意见，可通过第九条渠道投诉。

> ⚠️ **交付前必检**：注销通道必须**真实可用**（应用商店会实测），不可只写不做。

## 六、未成年人保护

1. 本产品**不面向不满十四周岁的儿童**提供服务。
2. 若你为**不满十四周岁的未成年人**，请你的父母或监护人阅读本政策，并在征得其**同意**后使用；我们不会在未取得监护人同意的情况下处理不满十四周岁未成年人的个人信息。
3. 若你为**已满十四周岁不满十八周岁**的未成年人，请在监护人指导下使用，并避免发布涉及个人隐私的信息。
4. 我们不会向未成年人推送不适宜其接触的信息；若发现涉及未成年人的不当内容，将依法处置并提供快捷举报通道。

## 七、我们如何保护你的个人信息

1. **传输安全**：全站 HTTPS 加密传输，证书固定（Certificate Pinning）；
2. **存储安全**：敏感数据加密存储，解密走**唯一受控入口**并同步写入审计日志；
3. **访问控制**：按最小必要授权，敏感操作留痕（审计日志）；
4. **关键校验**：手机号、身份证号等敏感信息**不以明文出现在日志中**；
5. **应急处置**：发生个人信息安全事件时，我们会按法律法规要求及时告知你并上报监管。

## 八、关于 AI 能力的特别说明（含授权条款）

本产品提供 **AI 辅助发布**功能（将你的一句话/一张图解析为结构化的发布内容）。关于此功能：

1. **解析在你同意本政策后才会启用**，你可随时改用手动填写；
2. **为改进 AI 解析能力**：当你使用 AI 辅助发布时，我们可能记录你的输入内容（如语音转写文本、图片识别文本）以及你**最终确认或修改后**的发布字段，用于**优化本产品的解析模型**；
3. 上述用于优化的数据将**去标识化**处理（不含手机号、身份证号等身份信息）；
4. **你可通过「我的」→「设置」关闭该用途**；关闭后不影响你继续使用 AI 辅助发布；
5. **AI 生成的内容会被标识为"AI 辅助生成"**，并请你在发布前核对，平台**不替你编造未提供的信息**。
