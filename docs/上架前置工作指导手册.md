**三条必须记住的结论**：
1. **P5 软著是全链路最长的腿**，且它**不依赖 app 做完**。所以它必须是第一个动的，不是最后一个。
2. **P4 → P7 是串行的**，ICP 不下号就无法做 APP 备案；而 P7 还额外依赖「能出一个签了名的安装包」。
3. **P1/P2/P3 是所有后续项的共同前提**，任一项拖延会同时推迟两条支线。

## 第 0 步：本周必须完成（8/24 – 8/28）

### P1 · 核对已有营业执照经营范围

**为什么必须做**
执照经营范围不含相关项，ICP 备案与商店入驻会在最后一步被拒；而经营范围变更本身要花 3–7 个工作日，越晚发现越致命。这是一个「**5 分钟能查、拖到后面要付 1 周代价**」的事项。

**办理入口**
- 查询：国家企业信用信息公示系统 https://www.gsxt.gov.cn/ → 输入企业名称 → 查看「经营范围」字段
- 如需变更：当地市场监督管理局政务服务网「经营范围变更」，或线下工商窗口

**前置依赖**：无。**本手册第一件事。**

**操作步骤**
1. 打开 gsxt.gov.cn 查询本企业，把「经营范围」全文复制出来。
2. 逐字比对是否含下列**任一**表述：「软件开发」「信息技术服务」「互联网信息服务」「技术服务、技术开发」「计算机软硬件开发」。
3. 命中任一项 → 本项完成，同时**截图存档**（后续 ICP、渠道入驻都要交执照，先把清晰扫描件准备好）。
4. 全部未命中 → 立即启动经营范围变更（当地政务网线上办，一般 3–5 个工作日出新执照），并把 P4 的启动日相应后移，同步更新说明文档 §1.3 里程碑。

**材料硬指标**
- 执照扫描件：彩色、四角完整、**加盖公章**（软著实名认证要求鲜章扫描件）、分辨率能看清统一社会信用代码。
- 建议一次做好三个格式备份：原始扫描 PDF、JPG（部分平台只收图片）、加盖公章版。

**驳回雷点**
- ❌ 用「经营范围里有『技术咨询』就算」的自我安慰 —— 咨询 ≠ 开发/服务，部分省通管局不认。
- ❌ 执照已过年检期或处于「经营异常」状态 —— ICP 备案会直接退回，需先解除异常。

**状态**：⬜ 未开始

### P2 · 购买域名 + 境内云服务器

**为什么必须做**
两个硬性用途，缺一不可：① APP 备案表**必填**「App 运行时连接的具体域名」；② 隐私政策**必须挂在自有域名下的独立 URL**，第三方托管（如 Notion、语雀、GitHub Pages）不被商店接受。此外 ICP 备案要求服务器在境内。

**办理入口**
- 阿里云 https://wanwang.aliyun.com/ / 腾讯云 https://dnspod.cloud.tencent.com/ / 华为云，任选其一
- ⚠️ **域名与服务器建议买在同一家**，因为 P4 的 ICP 备案与 P7 的 APP 备案都要通过「接入商」的备案系统提交，同一家可少走一轮接入商变更。

**前置依赖**：P1（备案主体须与执照一致）

**操作步骤**
1. 选域名：`.com` 或 `.cn` 均可。**建议与 App 名称有关联**（便于商店审核核对主体一致性），避免使用带连字符或数字的怪异域名。
2. 购云服务器：最低配即可（备案只校验服务器归属与地域），**必须选中国大陆节点**（香港、新加坡节点无法备案）。
3. 购买后立即在控制台完成**域名实名认证**（约 1–3 个工作日，未实名的域名无法提交备案）。
4. 记录三项信息备用：域名、服务器公网 IP、接入商名称。

**材料硬指标**
- 预算参考：域名约 30–60 元/年 + 入门云服务器约 70–100 元/年，**合计约 131 元/年**（经验值，随促销浮动）。
- 服务器地域：**中国大陆境内**，非港澳台及海外。

**驳回雷点**
- ❌ 域名未做实名认证就提交 ICP → 直接退回，白等一轮。
- ❌ 用海外服务器 → 无法备案，且商店会核查域名备案号。
- ❌ 域名注册人与执照主体不一致 → ICP 备案主体核验不通过。

**状态**：⬜ 未开始

### P3 · 锁定 App 正式名称 🔴 最高频驳回点

**为什么必须做**
下面四处名称**必须一字不差**：

| 出现位置 | 由谁登记 | 改动成本 |
|---|---|---|
| 软著登记证书上的软件全称 | P5 中国版权保护中心 | **改名 = 重新申请 = 重等 60 日** |
| APP 备案的应用名称 | P7 通管局 | 需变更备案 |
| 应用商店上架名称 | P8/提审 | 需重新提审 |
| 手机桌面显示名称 | 代码 `label` 字段 | 改代码即可 |

前三处任一不一致，商店审核会以「名称与备案/软著不符」驳回。**今天定死，之后不改。**

**办理入口**：无需办理，这是一次决策。但决策后要立即固化到代码与文档。

**前置依赖**：无

**操作步骤**
1. 定 **App 展示名**：`找鸭找`（已定）。
2. 定 **软著登记软件全称**。软著对名称有格式规范，建议结构为「**品牌 + 核心功能 + 软件性质 + 版本号**」，以「软件 / 系统 / 平台」结尾。
   - 推荐：`找鸭找本地供需信息共享平台软件 V1.0`
   - 不推荐：`找鸭找`（过于宽泛，易因重名或「名称不规范」被要求补正）
3. 版本号格式**全项目统一为 `V1.0`**（大写 V + 点 + 一位小数）。**禁止在任何材料中混用 `v1.0` / `Ver1.0` / `1.0` / `V1.0.0`**。
4. 固化落地三处：
   - Flutter `AndroidManifest.xml` 的 `android:label` 与 iOS `CFBundleDisplayName` → 填 `找鸭找`
   - 确定 `applicationId`（包名），格式为反向域名：`com.<企业域名主体>.zhaoyazhao`，**定后不可改**（改包名 = 重新备案 + 商店视为新应用）
   - 在本手册下方「名称与标识登记表」填写并冻结

**名称与标识登记表（冻结区，填完不改）**

### P4 · 提交 ICP 域名备案

**为什么必须做**
P7 的 APP 备案要求主体已完成 ICP 备案；且商店审核要核查域名备案号。这是备案串行链的第一环。

**办理入口**
在 P2 购买服务器的云厂商控制台内提交，**不要去工信部官网自己提交** —— 备案必须由「接入商」代为提交：
- 阿里云：https://beian.aliyun.com/
- 腾讯云：https://console.cloud.tencent.com/beian

**前置依赖**：P1（执照）+ P2（域名已实名 + 境内服务器）

**操作步骤**
1. 控制台 → 备案 → 新增网站备案，选择主体类型「企业/组织」。
2. 填主体信息：企业名称、统一社会信用代码、法人身份证、负责人手机与邮箱（**须能接收验证短信，后续核验要用**）。
3. 填网站信息：域名、服务器 IP、网站名称、服务内容（选「信息服务」）。
4. 上传：执照扫描件、法人身份证正反面、备案负责人身份证、**《信息安全管理承诺书》**（平台提供模板，打印签字盖章后扫描回传）。
5. 完成**真实性核验**（当前多为 App 内人脸识别或视频核验）。
6. 接入商初审（1–3 个工作日）→ 提交省通管局 → 短信核验（**收到后须在 24 小时内回复验证码，逾期作废重来**）→ 等待审核。

**周期**：官方上限 **20 个工作日**（来源：工信部）；实测常 7–10 个工作日。
**预期完成**：9/02（乐观）/ 9/21（上限）

**材料硬指标**
- 域名注册人 = 执照主体名称，**完全一致**。
- 网站名称不得含「中国」「官方」等受限词，不得直接用行业通用词。

**驳回雷点**
- ❌ 短信核验码未在 24h 内回复 → 整单作废重新提交，损失一整轮周期。
- ❌ 备案期间更换服务器或域名解析 → 审核中断。
- ❌ 网站名称与备案主体无关联性 → 部分省通管局要求整改。

**状态**：⬜ 未开始

## 第 1 步：软著（最长的腿，8/25 必须提交）

### P5 · 提交软件著作权登记申请

**为什么必须最先做**

| 事实 | 依据 |
|---|---|
| 华为 / OPPO / vivo **强制要求软著**，无软著直接驳回、无例外 | 各渠道开发者协议 |
| 审查时限「自受理日起 **60 日**」 | 《计算机软件著作权登记办法》第二十条；中国版权保护中心官网「办理时限」页原文 |
| 加急仅「优先处理」，**官方明示审核周期不变** | 中国版权保护中心 |
| 官费 **0 元** | 财税[2017]20 号，自 2017-04-01 起停征软件著作权登记费；国家政务服务平台该事项「是否收费：否」 |
| **不需要 app 做完** | 只需 60 页源码 + 说明书 + 申请表；源码可来自已完成的模块 |

> **⚠️ 关于「60 日」还是「60 工作日」——这是本项目排期的一处口径分歧，处理方式如下：**
> - **法条与官方口径为「60 日」**：《计算机软件著作权登记办法》第二十条原文「自受理日起 **60 日**内审查完成」，中国版权保护中心官网「办理时限」「办理步骤」两页均照此表述。
> - **另有政务口径为「60 工作日」**：国家政务服务平台「计算机软件著作权登记初审」事项列「法定办结 60 工作日 / 承诺办结 20 工作日」（北京市版权局代办口径）。
> - **实操普遍长于法定值**：受理前还有「待受理 1–3 工作日 + 受理中 3–5 工作日」，通过后还有「待发证 5–10 工作日」；业内普遍反馈**从提交到拿证 2–3 个月**，材料被补正则 3–4 个月（经验值）。
> - **本项目取值决定**：排期一律按 **60 工作日 → 8/25 提交，预计 11/17 下证** 作为**保守规划值**。理由是即使法定为 60 自然日，叠加受理与发证前后段也落在同一量级；按保守值排期，若实际提前下证则上架窗口自然宽松，反之不会导致里程碑崩塌。**本项目所有文档统一使用此保守值，不因法条字面为「60 日」而提前上架承诺。**

**办理入口**
中国版权保护中心 https://www.ccopyright.com.cn/ → 用户注册 → 实名认证 → 在线填报

**前置依赖**：P1（执照盖章扫描件）+ P3（软件全称与版本号已冻结）

**操作步骤（官方六步流程）**

> 官方流程：账号注册 → 实名认证 → 填报提交 → 登记机构受理 → 登记机构审查 → 取得登记证书

**① 账号注册（当天）**
- 注册中国版权保护中心账号。⚠️ **同一手机号只能绑定一个企业或一个个人主体**，请用企业专用手机号，不要用私人常用号，后续变更麻烦。

**② 实名认证（1–3 个工作日）**
- 企业主体：上传**加盖公章的营业执照扫描件**，再通过「对公账户打款验证」或「法人扫码验证」二选一完成校验。
- ⚠️ **未完成实名认证无法创建业务订单**，这一步不能与填报并行，必须先过。

**③ 准备三份鉴别材料（这是全流程唯一真正耗人力的部分，约 1–2 天）**

**材料 A：源代码（60 页）**

| 要求 | 具体指标 |
|---|---|
| 页数 | 总量 >60 页 → 提交**连续前 30 页 + 连续后 30 页**；不足 60 页 → 全部提交 |
| 每页行数 | **每页有效代码 ≥50 行**，空行与注释**不计入**有效行数 |
| 页眉 | **每页页眉必须打印「软件全称 + 版本号」**（即 P3 冻结值），加页码 |
| 格式 | **必须是可选中的文本**（PDF 或 Word 导出）。❌ **严禁用代码截图** —— 审查系统需要提取文本做 AI 比对，截图会被判定材料不合格 |
| 内容 | 须体现自主开发逻辑。❌ 不能整篇是框架脚手架自带模板代码，会被判「独创性不足」 |
| 清理 | **必须删除第三方库/模板里的原始版权声明**（如 `Copyright (c) XXX Inc.`），否则权属存疑 |

- 实操建议：从本项目 Flutter 端 + 后端已完成模块中挑选**业务逻辑最密集**的文件（如发布模板引擎、完整度分级规则引擎、地图聚合逻辑），拼成前 30 页；后 30 页取另一批业务文件。

**材料 B：操作说明书**

| 要求 | 具体指标 |
|---|---|
| 页数 | **建议 ≥10 页**，10–15 页为稳妥区间 |
| 形式 | **图文结合**：每个核心功能配「文字说明 + 界面截图」 |
| 一致性 | 截图内显示的软件名与版本号，**须与申请表、源码页眉完全一致** |
| 覆盖 | 至少覆盖五大 P0 闭环：账号登录/实名 → 发布 → 首页地图 → 详情 → 联系中转 |
| 页眉 | 同源码，打印软件全称 + 版本号 |

- ⚠️ 说明书里写的功能，**必须在源代码里有对应实现**，也必须在申请表功能描述里有对应表述。三处对不上是最高频的补正原因。
- 截图来源：可用 Figma 原型骨架的界面截图，但**须与最终实现一致**，不要放不存在的功能。

**材料 C：申请表功能描述**

| 要求 | 具体指标 |
|---|---|
| 字数 | **500–1300 字**。⚠️ 2026 年起，仅写一两百字的会**直接下补正** |
| 写什么 | 研发背景 → 技术架构 → 核心功能模块 → 关键技术实现 → 适用业务场景 |
| 不写什么 | ❌ 杜绝营销话术（「行业领先」「颠覆式创新」「用户体验极佳」） |
| 一致性 | 描述的每一个功能，须在源码与说明书中有对应体现 |

## 第 2 步：ICP 通过后

### P6 · 编写隐私政策并挂上自有域名

**为什么必须做**
应用商店与工信部均要求隐私政策可通过**独立 URL 访问**；且首启弹窗未同意前**禁止读取任何设备信息**是《个人信息保护法》与商店审核的双重硬要求。本产品含定位与 UGC，属重点核查类目。

**办理入口**：无需审批，自己写 + 挂 P2 的域名。

**前置依赖**：P2（域名与服务器）

**操作步骤**
1. 写正文，**必须完整覆盖**下列七项：
   - 收集哪些个人信息、各自用途（**逐项对应权限**）
   - 第三方 SDK 清单：⚠️ **高德地图 SDK 必须列明**（名称、提供方、收集的信息类型、用途、隐私政策链接）
   - 数据存储位置与期限（身份证信息口径须与 PRD §4.7 一致：**只存不可逆哈希 + 后 4 位明文，OCR 原照 7 天删除**）
   - 用户权利与**账号注销通道**（须真实可用，商店会实测）
   - 未成年人保护条款
   - 数据共享/转让/公开披露规则
   - 联系方式与投诉渠道
2. 挂到自有域名下的固定路径，如 `https://<你的域名>/privacy.html`，确保**未登录可访问、手机浏览器可正常渲染**。
3. 客户端首启弹窗：先弹隐私协议 → 用户同意后才调 `AMapInitializer.updatePrivacyAgree`（这条已写入 PRD §6.7，与合规同一要求）。

**材料硬指标**
- 必须是独立 HTML 页面，**不能是 App 内写死的纯文本**（备案与商店要填 URL）。
- 权限用途说明须逐条具体。定位权限须写明「用于展示附近供需信息与计算距离」，不可只写「用于提供服务」。

**驳回雷点**
- ❌ 挂在第三方文档平台（Notion / 语雀 / 石墨）→ 不被接受。
- ❌ 未列高德 SDK → 华为、vivo 会以「第三方 SDK 披露不完整」驳回。
- ❌ 首启前静默获取设备信息/定位 → **高频驳回点**，商店会用抓包实测。
- ❌ 写了注销通道但实际无法注销 → 一票驳回。

**状态**：⬜ 未开始

### P7 · 工信部 APP 备案

**为什么必须做**
自 **2023-09-01** 起，新开办 APP 须完成备案才能上架应用市场。法规依据：工信部《关于开展移动互联网应用程序备案工作的通知》+《反电信网络诈骗法》第二十三条。

**办理入口**
与 P4 同一处 —— **接入商（服务器提供商）的备案系统**，由**主办者所在省级通信管理局**审核。
- 阿里云 / 腾讯云 / 华为云备案控制台 → 「APP 备案」

**前置依赖**：P4（ICP 已下号）+ P3（包名冻结）+ **一个已签名的安装包**

**操作步骤**
1. 先出一个签名包（不必是完整功能版，但**包名与签名证书须是正式发布用的那一套**，之后不能换）。
2. 取备案三要素：
   | 要素 | 安卓（Android） | iOS / HarmonyOS |
   |---|---|---|
   | 包名 | `applicationId`，反向域名格式 `com.xxx.zhaoyazhao` | Bundle ID |
   | 公钥 | 签名证书公钥（16 进制） | 同 |
   | 特征值 | **证书 MD5 值**（16 进制） | **证书 SHA-1 值**（16 进制） |
   - 安卓取法：`keytool -list -v -keystore <你的.jks> -alias <别名>`，输出中取 MD5 与公钥。
   - 华为 AGC 取法：AGC 下载开发者证书 → **删除根证书与中间证书，仅保留服务器证书** → 查看详细信息 → 取公钥与 SHA-1 指纹。
3. 填备案表：App 名称（= P3 冻结值）、包名、公钥、MD5/SHA-1、**App 运行时连接的具体域名**（= P2 域名）、服务内容分类。
4. 申报两项附加信息：**是否对外提供 SDK 服务**（选否）、**是否使用第三方 SDK**（选是，填服务商「高德地图」与类型「地图定位」）。
5. 提交 → 接入商初审 → 省通管局审核 → 下发 **APP 备案核准号**（须在 App 内或官网展示）。

**⚠️ iOS 与安卓属不同运行平台，需分别备案。** 若两端同期上架，需提交两条备案记录。

**周期**：ICP 通过后约 **7 个工作日**（来源：工信部 2023 年 105 号文实施口径）
**预期完成**：9/11（乐观）

**驳回雷点**
- ❌ 备案用的签名证书与最终上架包不是同一套 → 商店校验 MD5 不符，必须重新备案。
- ❌ App 名称与 P5 软著、P4 ICP 主体不一致 → 退回。
- ❌ 只备安卓就去上 iOS → 苹果侧要求提供对应平台备案号。

**状态**：⬜ 未开始

## 本产品特有的四条合规风险（须提前规避，非可选）

### 1. UGC 属性明确，必须企业主体
产品含用户自主发布 + 陌生人联系，安卓渠道判定为「社区类」，**个人主体一律拒审**。→ 已有执照，此项已解（P1 核对经营范围即可）。

### 2. 🔴 不触发 ICP 经营许可证（B25）的红线 —— 这条红线现在是护城河
只要出现下列**任一项**，五大安卓商店即强制要求 ICP 经营许可证（门槛：**注册资本 ≥100 万 + 3 人连续 1 个月社保**）：
- 会员充值 / 付费解锁 / 虚拟打赏 / 平台广告 / 商家入驻

本产品 Scope **已永久排除支付与商业化**（见 PRD 红线），恰好规避此项。
**⚠️ 这意味着：任何「加个会员」「接个广告」的增收想法，都会把上架周期再拉长一到两个月并触发实缴资本与社保门槛。不可为增收而破。**

### 3. 位置权限是高频驳回点
地图为核心功能，定位权限申请**必须有明确用途说明**，且**首启同意前不得静默获取**。与 P6 隐私政策、PRD §6.7 高德初始化时序为同一件事的三个面。

### 4. 算法备案潜在风险
BRD 规划的 Batch2 LR+GBDT 匹配属「个性化推荐算法」，可能触发《互联网信息服务算法备案》。
- **内测包阶段用规则加权（阶段 0）不触发**；
- 上架后若开启模型推荐，需先评估此项再灰度。
