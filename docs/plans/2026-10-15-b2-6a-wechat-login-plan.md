### 1.2 申请步骤（官方流程，逐步可执行）

1. **注册微信开放平台账号** —— 入口 `https://open.weixin.qq.com/` → 右上角「注册」
   - ⚠ **邮箱必须唯一**：**未**注册过微信开放平台、**未**注册过微信公众平台、**未**绑定私人微信账号（否则报 `该邮箱已被占用，请更换其他邮箱`）
   - 填邮箱 + 密码 → 同意《微信开放平台开发者服务协议》→ **登录邮箱点激活链接** → 填验证码完成注册
2. **登记主体信息** → 确认主体（本项目 = **企业主体**：营业执照 + 法人身份证信息）
3. **完成开发者资质认证** —— 路径「微信开放平台 - 账号管理 / 账号中心 - 开发者资质认证」
   - **需支付认证服务费**（金额以开放平台页面实际显示为准；公开常见口径为 **300 元/年**，本文件不把该数字当既成事实）
   - 企业主体通常需提交：营业执照、法人身份证、对公账户打款验证等（以页面指引为准）
   - 认证后：可创建 **50 个**移动应用（未认证仅 10 个）
4. **创建移动应用** —— 管理中心 - 移动应用 - 「创建移动应用」
   - 选 **「直接创建」**（「复用多端应用快速创建」需已绑定且已上线的多端小程序，本项目不适用）
   - 逐项填 §1.3 的表单七项 → 提交审核
5. **提交审核 → 等待结果**
   - 审核周期 **1–7 个工作日**（官方口径：**不含**周末与法定节假日；复杂逻辑会延长）
   - ⚠ **不支持撤回审核**；不通过则按驳回原因改后重提；不通过期间按**上一次通过的状态**运行
6. **取得凭据** —— 审核通过后得 **AppID**（+ **AppSecret**）
   - ⚠ **微信登录是独立「能力」，须再申请并通过审核**（并非创建应用即自动拥有）

## 三、目标与验收

**总目标（条目原文）**：端到端可用 —— 授权 → `user_identity` 落 `wechat` 身份 → 签发 Token；**不改表、不迁移**。

**端到端链路**（微信 OAuth2.0 `authorization_code` 模式，官方口径）：

1. 客户端（Android）拉起微信授权 → 得临时票据 **code**（`scope=snsapi_userinfo`，**只能填此值**）
2. 后端用 **AppID + AppSecret + code** 调微信接口换 **access_token**
3. 用 access_token 取用户信息（openid / unionid / 昵称 / 头像）
4. 按 `openid`（或 `unionid`）落 `user_identity` 的 `wechat` 身份行；无账号则建账号
5. 签发本产品 Token（复用既有签发链路）

**验收点**：
- ✅ 端到端走通（真机拉起微信 → 落库 → 拿到 Token）
- ✅ `user_identity` 落一条 `identity_type='wechat'` 行；同 openid 重复登录**不重复建行**（幂等）
- ✅ 未改表、未迁移（**零** DDL）
- ✅ 门禁全绿（后端 `mvn -o clean test` / `flutter analyze` / `flutter test`）

**契约先行**：先按 OpenAPI 补 `auth` 域微信登录端点（路径 / 载荷 / 响应 / 错误码），前端用契约 + 内存 mock 打通，后端就绪后切真联调。
