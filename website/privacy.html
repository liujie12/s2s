找丫找 隐私政策

版本 v1.0.0　·　生效日期：【待填：上线日】　·　最近更新：2026-10-23

一、引言

本政策由 合肥嘉联企业管理咨询有限公司（以下简称“我们”）制定，适用于我们运营的「找丫找」移动客户端（以下简称“本产品”）。

我们深知个人信息对你的重要性，将按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》《常见类型移动互联网应用程序必要个人信息范围规定》《移动互联网应用程序信息服务管理规定》《未成年人网络保护条例》《互联网信息服务算法推荐管理规定》等法律法规的要求，采取相应的安全保护措施，尽力保护你的个人信息安全可控。

核心承诺：

  1. 最小必要：只收集实现功能所必需的信息，不收集与提供服务无关的个人信息；
  2. 告知同意：在你明确同意本政策前，不读取任何设备信息、不申请定位权限、不初始化任何第三方 SDK；
  3. 可拒绝：你可以拒绝或撤回同意；拒绝不影响你浏览本产品的基本内容（地图与定位功能将不可用）；
  4. 境内存储：本产品服务器部署在中国境内，个人信息存储于中国境内。

2.1 敏感个人信息与单独同意

以下属敏感个人信息，我们仅在取得你的单独同意（或系统权限授权）后处理：

  • 姓名、身份证号（实名认证）：仅用于身份核验。核验通过后，姓名以加密形式存储（解密受严格权限与审计约束，仅用于核验复核与客服核实），身份证号仅保存不可逆哈希值与后 4 位明文，不保存身份证号完整明文。
  • 资质证照原件图片：仅用于人工审核；核验完成后 7 天内自动删除（含对象存储中的原件与数据库引用）。
  • 精确位置信息：仅在你在系统弹窗中授权定位后收集；你可随时在系统设置中关闭。

四、我们如何共享、转让、公开披露你的个人信息

  1. 我们不会出售你的个人信息。
  2. 共享：仅在下列情形共享，且要求接收方遵守同等保护义务：
    • 履行功能所必需的服务商（地图、短信、实名核验、对象存储、AI 解析）——见第二条 2.2 / 2.3；
    • 你主动使用“联系中转”功能、选择向对方展示联系方式时（此时仅向你选择的目标展示脱敏/经你同意的联系方式）；
    • 法律法规要求或有权机关依法要求时；
    • 取得你的单独同意的其他情形。
  3. 转让：原则上不转让；如发生合并、分立、收购等，将告知你并要求承继方继续受本政策约束，否则重新征得同意。
  4. 公开披露：除你主动发布的信息（将在本产品内公开展示）外，不公开披露你的个人信息。

五、你的个人信息权利

你对自己的个人信息享有下列权利，可通过本政策第十条的联系方式行使（我们将在 15 个工作日内答复）：

  1. 查阅、复制：查阅获知你账号下的个人信息；
  2. 更正、补充：更正不准确的个人信息；
  3. 删除：在你撤回同意、注销账号，或处理目的已实现等情形下请求删除；
  4. 撤回同意：
    • 关闭位置权限（系统设置）；
    • 关闭 「我的」→「设置」→「隐私」→「个性化推荐」；
    • 关闭 「我的」→「设置」→「隐私」→「AI 数据用于改进」；
  5. 注销账号：通过 「我的」→「设置」→「注销账号」 提交注销申请；提交后有 7 天冷静期（可撤回），冷静期届满后账号信息、实名信息及你名下的全部发布信息（含媒体文件）将按第三条期限被删除或匿名化（法律法规另有要求的除外）；
  6. 投诉举报：对本政策或个人信息处理有疑问、意见，可通过第十条渠道投诉。

六、未成年人保护

  1. 本产品不面向不满十四周岁的儿童提供服务，也不会主动收集其个人信息。
  2. 若我们发现在未取得监护人同意的情况下收集了不满十四周岁儿童的个人信息，将删除相关信息；监护人可通过第十条渠道联系我们。
  3. 若你为已满十四周岁不满十八周岁的未成年人，请在监护人指导下使用，并避免发布涉及个人隐私的信息。
  4. 我们不会向未成年人推送不适宜其接触的信息；若发现涉及未成年人的不当内容，将依法处置并提供快捷举报通道。

七、我们如何保护你的个人信息

  1. 传输安全：全站 HTTPS（TLS 1.2 及以上）加密传输；
  2. 存储安全：手机号、姓名、联系方式等敏感字段加密存储；解密走唯一受控入口并同步写入审计日志；
  3. 访问控制：按最小必要授权，敏感操作留痕（审计日志保留 180 天）；
  4. 日志脱敏：手机号、身份证号等敏感信息不以明文出现在日志中；
  5. 应急处置：发生或可能发生个人信息泄露、篡改、丢失的，我们将立即采取补救措施，并立即通知你（无法逐一通知时将发布公告）及履行个人信息保护职责的部门。

本产品提供 AI 辅助发布功能（将你的一句话 / 一张图解析为结构化的发布内容）。关于此功能：

  1. 解析在你同意本政策后才会启用，你可随时改用手动填写；
  2. 服务提供方：AI 能力由阿里云百炼平台的通义千问模型提供（受托处理方）。该生成式人工智能服务备案号 ZheJiang-TongYiQianWen-20230901，算法备案号 网信算备330110507206401230035号；
  3. 为改进 AI 解析能力：当你使用 AI 辅助发布时，我们可能记录你的输入内容（语音转写文本、图片识别文本）以及你最终确认或修改后的发布字段，用于优化本产品的解析模型；
  4. 上述用于优化的数据将去标识化处理（不含手机号、身份证号等身份信息），且不会用于训练第三方模型；

九、关于排序与个性化推荐

  1. 本产品的列表排序基于客观规则：距离、发布时间、信息完整度（综合排序权重为时效 40% + 距离 40% + 完整度 20%）。
  2. 我们不基于你的浏览、搜索、联系等行为建立兴趣画像，也不做定向内容推荐；排序对所有用户采用同一套规则。
  3. 你可在 「我的」→「设置」→「隐私」→「个性化推荐」 关闭该功能。关闭后，综合排序回落为仅按距离排序；你主动选择的其他排序方式不受影响。
  4. 关闭该功能不影响你正常发布、浏览与联系。
