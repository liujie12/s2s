第一条 导言与协议接受

1.1 本协议是你与 合肥嘉联智能科技有限公司（以下简称“我们”）之间就使用「找丫找」移动客户端及相关服务（以下简称“本服务”）所订立的协议。

1.2 请你在使用本服务前，认真阅读并充分理解本协议全部内容，特别是以粗体标注的免除或限制责任条款。你勾选“我同意用户协议与隐私政策”或实际使用本服务，即视为你已阅读并同意本协议。

1.3 本协议与《隐私政策》共同构成完整约定；《隐私政策》为本协议不可分割的组成部分。

1.4 若你不满十八周岁，请在监护人陪同下阅读本协议，并在取得监护人同意后使用本服务。本服务不面向不满十四周岁的儿童提供（详见第十二条）。

第二条 定义

2.1 本服务：我们提供的、基于地理位置的信息发布与浏览撮合服务，包括地图浏览、信息发布、检索筛选、联系中转等。

2.2 用户内容：你通过本服务上传、发布的文字、图片、价格、位置等信息。

2.3 信息撮合：本服务仅为你与信息发布方/需求方之间提供信息展示与联系通道，不参与任何交易，不提供任何担保。

2.4 个性化排序：指在列表检索中，按“时效、距离、信息完整度”三项客观规则加权计算展示顺序（权重见 4.5）。该排序不基于你的浏览、搜索、联系等行为做用户画像。

第三条 账号注册与登录

3.1 你可以通过手机号码 + 短信验证码注册或登录；也可通过微信授权登录（以微信返回的账号唯一标识完成身份绑定）。你应保证注册所用手机号为你本人合法持有，并保证第三方账号为你本人所有。

3.2 你应妥善保管账号信息，因你保管不善造成的损失由你自行承担。你发现账号被盗用的，应立即通知我们。

3.3 实名认证是增益项，不是使用门禁。未实名与已实名的能力差异如下（本表为完整列举，不含表外限制）：

第四条 平台服务说明与我们的立场

4.1 我们只做信息撮合，不做交易。本服务不提供线上支付、结算、订单、履约、评价等交易功能；你与对方之间的任何线下交易、资金往来、风险与纠纷，由你们自行承担，与我们无关。

4.2 我们不做商业化分级。我们不售卖完整度角标（🟢🟡🔴）、不售卖实名或资质徽章、不售卖曝光或排序特权、不设会员等级与信誉等级。本服务本期不向用户收取任何费用。

4.3 提供联系方式走统一中转页。本服务不提供站内即时通讯（IM）；你通过“联系中转页”获取对方联系方式，页面会对号码作中间 4 位脱敏展示。为防骚扰与滥用，我们对查看联系方式的频次设有上限，触发上限时将暂时限制访问。

4.4 服务可能变更或中断。因设备、网络、第三方服务（含地图服务）等原因，可能导致服务中断或数据延迟，我们将尽力修复但不承担因此产生的间接损失。

4.5 排序与个性化推荐：

  1. 列表检索的默认排序为按距离由近到远；你可切换为发布时间、价格、信息完整度或综合排序。
  2. 综合排序按客观规则加权：时效 40% + 距离 40% + 信息完整度 20%。该计算不使用你的行为画像，也不针对你个人做定向内容推荐。
  3. 你可在 「我的」→「设置」→「隐私」→「个性化推荐」 随时关闭。关闭后，综合排序将回落为仅按距离排序；其余由你主动选择的排序方式不受影响。
  4. 关闭该开关不影响你使用本服务的其他功能。

第五条 信息完整度分级说明

5.1 你对信息的完整度会被标记为 🟢 / 🟡 / 🔴 三档（界面以矢量色点 + 文字双通道展示），判定依据是纯规则计数（必填项是否齐全、位置精度、分类匹配），不是对你的评价。

5.2 该分级只作用于信息本身（影响是否进入推荐池与展示形态），不对发布者做信誉评分、不做人格标签、不做等级体系。

5.3 你可在“发布完成页”看到“还差哪几项即可升档”的提示，并可随时补齐。

第六条 信息有效期与下架规则

6.1 发布信息的有效期默认为 7 天，不提供其他可选值。

6.2 有效期届满前，你可一键刷新续 7 天，可无限次刷新。

6.3 有效期届满后，信息将自动从地图与推荐池下架（不再向他人展示），但仍保留在“我的发布”中，你可随时刷新恢复展示。

6.4 你可以自行删除你发布的信息。已删除信息我们可能按法律法规要求保留必要记录。

第八条 内容审核、举报与处置
