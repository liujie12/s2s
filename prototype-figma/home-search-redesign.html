SPEC 01

结构变化

与当前实现对照

顶部：从 48px AppBar 到沉浸式浮层

  • 删除 AppBar：左上角「丫圈」标题整条移除，地图延伸到状态栏下方。
  • 搜索栏固定：距安全区 8、左右 16，358 × 48，圆角 24，不随地图拖动或页面滚动。
  • 语音入口：文字「语音」改为 36 × 36 话筒圆钮（底 #E6F6F8，图标 #0B7C8C）。
  • 筛选入口：话筒左侧加 32 × 32 漏斗圆钮，点击打开底部面板；点文字区域仍只聚焦键盘。
  • 输入态：有文字时话筒变为同尺寸「提交」箭头（实心主色），清空后恢复话筒；漏斗常驻。

筛选栏：解析出条件后才出现

  • 默认不渲染：没有任何条件时，搜索栏下方不占位、不显示空态入口。
  • 出现时机：语音或文字解析出 ≥ 1 个条件后，180ms 从搜索栏下方滑入；条件全部删除后 150ms 淡出。
  • 来源唯一：只装解析出的条件 + 面板中用户主动新增的条件，不再预置 5km / 资源+需求 / 全部分类。
  • 默认态入口：搜索栏内 32 × 32 漏斗圆钮打开面板；筛选栏出现后，点栏内任意位置同样是入口。
  • 命中数：移到左下角「附近 N 条」状态胶囊，筛选栏只装条件，不混入计数。
  • 溢出：单行横滑，右侧渐隐提示还有更多，不做换行吃掉地图。

底部面板：浮层卡片改为 Bottom Sheet

  • 唤起：搜索栏内漏斗圆钮，或筛选栏内任意位置（含 chip 主体），均打开同一个面板。
  • 尺寸：高 500（约 59% 屏高），顶部圆角 24，拖拽把手 36 × 4。
  • 价格：双端滑杆 + 两端数值框；拖动滑杆选区间，点数值可精确输入，键盘只在点数值时出现；右侧「不限」一键清空。拖动滑杆时两侧数值框实时回写（不依赖失焦，键盘未收也同步）。
  • 价格映射：左端 = 下限，右端 = 上限；清空某一端 = 该侧不限；手动输入可超出滑杆量程，滑杆置顶但数值以输入为准。
  • 分类：一级 3 × 2 网格（全部 + 5 大类），点主体选整类、点 › 逐级下钻到二级 / 三级叶子，叶子可多选。
  • 无视觉遮罩：不压暗地图，让用户直接看到条件变化后的 Pin 结果；地图页仅叠一层透明层承接「点外部收起」，列表页复用弹层遮罩。
  • 关闭：点面板之外（地图页点地图空白、列表页点遮罩）即收起，没有底部确认按钮；收起即按最新条件取数。
  • AI FAB：面板展开时自动上移到面板顶边之上，入口不消失。

条件回写：面板操作即追加

  • 实时：面板里切换范围 / 供需 / 价格 / 分类，筛选栏同步出现或移除对应 chip。
  • 追加不覆盖：面板新增项直接插入已有 chip 序列（按范围 → 供需 → 分类 → 价格 → 地点排序）。
  • 关闭保留：关闭面板不清空；只有 chip 上的 × 或面板「重置」才会移除。
  • 首次新增：从搜索栏漏斗打开面板并选中第一个条件时，筛选栏随之滑入。
  • 来源可辨：语义解析出的 chip 用主色描边 + 主色圆点；面板新增用中性描边 + 灰点。

列表页：同一套搜索栏与筛选栏

  • 保留 AppBar：返回 + 「附近信息」+ 「地图」跳转；去掉右侧 tune 图标，筛选入口收进搜索栏漏斗。
  • 同一搜索栏：放大镜、占位文案、漏斗、话筒/提交与地图页完全一致。
  • 动态筛选栏：解析出条件后同样滑入；chip 样式、排序与点击行为不变。
  • 命中数：移到结果行左侧「N 条结果」，与五个排序档位同排，不再塞进筛选栏。
  • 同一面板：漏斗打开同一个底部面板（价格滑杆、3 × 2 分类、图例全部同源）。

跨页一致性：条件只有一份

  • 条件同源：两页都读 effectiveFilterProvider，切页不重置搜索或筛选。
  • 搜索栏同源：同一个控件、同一份文本，不出现「地图 3 个 Pin、列表 12 条」。
  • 排序独立：列表排序不写回筛选态，改排序不会触发地图重绘。
  • 空态一致：列表空态回显当前 chip 摘要，并保留「扩大到全城」入口。

分类：一级 → 二级 → 三级叶子

  • 一级：全部 + 5 大类，3 × 2 网格；点选 = 该大类下全部叶子。
  • 二级：点 chip 右侧 › 进入；面包屑「服务 › 家政/保洁」可逐级回退。
  • 三级：叶子多选；选中用分类 deep 色填充，实时追加同名 chip。
  • 跨大类：切换一级时保留已选叶子；已选分支用圆点或计数标记。
  • 全部：二级/三级的「全部」= 该层下所有叶子，不额外造筛选维度。

分类与请求：仍然只传叶子 ID

  • 映射：一级 = 该大类全部叶子 ID；二级 = 该二级全部叶子；三级 = 单个叶子 ID。
  • 契约不变：请求仍走 leafCategoryIds，不新增参数、不改分类树版本口径。
  • 状态扩展：现有 categories 是 Top 大类集合，需补叶子 ID 集合（或复用搜索槽位），否则三级选择落不到请求。
  • chip 文案：用叶子或二级名；多个叶子各占一枚 chip，顺序按分类树遍历。
SPEC 02

交互规则

11 条，可直接作为验收项

#触发行为
1进入首页只渲染固定搜索栏（内含漏斗入口）、右侧列表浮钮、左下角「附近 N 条」；筛选栏整体不出现。
2点击话筒唤起现有语音面板；解析出条件后，筛选栏从搜索栏下方滑入，chip 逐条淡入，右上按钮列同步下移 40。
3输入文字并提交解析结果同上；话筒在输入态变为提交箭头，避免多一个「搜索」按钮撑宽搜索栏。
4点击搜索栏内漏斗 / 筛选栏任意位置打开底部面板；点 chip 主体时，面板滚动并高亮该 chip 对应分组。
5面板内切换任一条件立即写入筛选态，筛选栏同步追加 / 移除 chip；地图 Pin 与左下角命中数同步刷新。
6点击 chip 上的 ×只删除这一条条件，面板不弹出；若该维度回到默认值，chip 消失而不是变成「5km」。
7关闭面板点面板之外（地图页点地图空白 / 列表页点遮罩）即收起，无底部确认按钮；收起时立即按最新条件取数，条件与 chip 全部保留。
8取数中 / 取数失败左下角命中数显示「—」；失败时变为「加载失败 · 重试」，点击重取，不阻塞底图与筛选栏。
9解析失败 / 没听懂筛选栏保持隐藏；搜索栏下方浮出深色提示「没听懂 · 重试」，点击重试，8s 自动消失。
10切到列表页同一搜索栏与筛选栏直接复用；地图上解析出的条件在列表页继续生效，结果行显示「N 条结果」，排序不写回筛选态。
11分类继续下钻点一级大类 = 整个大类；点 chip 右侧 › 进入二级，再进入三级叶子；面包屑逐级回退；叶子多选并实时追加同名 chip，请求仍只传叶子 ID。

SPEC 05

落地映射

确认设计后再改代码

前端文件

  • features/map/map_screen.dart：删除 _buildAppBar()；搜索栏拆成「放大镜 + 输入 + 漏斗 + 话筒/提交」，筛选栏条件非空才出现；右侧按钮列只保留列表与定位，且定位按钮仅在相机偏离视口短边 20% 时出现（已在当前位置就不显示，避免误判定位状态）。
  • features/discovery/condition_band.dart：拆成 SearchField（含话筒 / 提交态）与 ChipBar；ChipBar 仅在条件非空时渲染，命中数移出为左下角状态胶囊。
  • features/discovery/filter_panel.dart：保留四行控件与图例，增加把手、标题行；没有底部主按钮（点面板外即收起并按最新条件取数）；价格行改为 RangeSlider + 两端数值框（拖动滑杆时数值框实时回写，点数值才唤起键盘），去掉预设档位；分类补齐二级/三级下钻与面包屑；选中态只读 explicitCategorySelectionProvider 投影、写入统一走 searchConditionsProvider。
  • features/discovery/list_screen.dart：用同一 SearchField + ChipBar 替换 ConditionBand；删除 AppBar 的 tune 图标；命中数并入结果行，与排序同排；漏斗复用同一面板。
  • features/discovery/effective_filter.dart：投影层需要补「是否被用户显式设置」标记，UI 只渲染显式项；否则默认 5km / 资源+需求 / 全部分类会再次出现。
  • features/discovery/discovery_filter.dart：除 Top 大类集合外补叶子 ID 集合与下钻层级；分类 chip 文案取叶子/二级名；filterPanelExpandedProvider 可保留用于 FAB 避让。

本轮已确认的前提

  • 筛选栏动态出现：默认不渲染，只在解析出条件后出现在搜索栏下方。
  • 默认态入口：搜索栏内漏斗打开面板，避免默认栏占位。
  • 输入态：话筒在输入文字后切换为提交箭头。
  • 面板：不压暗地图，实时看 Pin 变化。
  • 命中数：从筛选栏移到左下角「附近 N 条」。
  • 价格：双端滑杆 + 两端数值框，滑杆不顺手时点数值精确输入。
  • 列表页：同一搜索栏、筛选栏与面板；命中数并入结果行，排序不写回筛选态。
  • 分类：支持一级 → 二级 → 三级叶子下钻；叶子多选，请求仍只传叶子 ID。
